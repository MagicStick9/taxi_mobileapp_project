## 🌐 English Description
A full-stack mobile taxi booking application prototype. The repository contains the mobile client application and the backend architecture required to process bookings and handle user accounts.

### 🛠️ Tech Stack
* **Starter Animation:** JavaScript + Lottie
* **Frontend (Android Client):** Android Studio, Java
* **Network Client:** Retrofit (JSON request/response transformation)
* **Maps Integration:** Google Maps API (maps and routing)
* **Backend (Server):** Node.js + Express.js (API, request processing)
* **Database:** MongoDB (data storage)
* **Security:** JWT (JSON Web Tokens for secure user authentication)

### ⭐ Key Features
* **User & Driver Authentication:** Registration and secure login logic via JWT tokens.
* **REST API Architecture:** Fast JSON data exchange between the mobile client and the server.
* **Interface Personalization:** Built-in theme switching support in settings (Light / Dark).
* **Informative Markers:** Map markers displaying origin and destination addresses
* **Smart Maps:** Automatic shortest route calculation between points A and B
* **Interactive Bottom Sheet:** Pull-up bottom panel for placing orders

### 🖥️ HTTP Admin Panel and Database
* **Real-time Update:** The web panel automatically synchronizes with the database
* **User Management:** Updating the user list, deleting an account
* **Password Hashing:** Robust password hashing using BCrypt combined with strict validation rules (minimum length, complexity requirements, and special characters) to ensure maximum credential protection

## 💬 Описание на русском
Полнофункциональный прототип мобильного приложения для заказа такси. Репозиторий содержит клиентскую мобильную часть и серверную архитектуру для управления аккаунтами пользователей.

### 🛠️ Технологический стек
* **Стартовая Анимация** JavaScript + Lottie 
* **Клиентская Часть (Android):** Android Studio, Java
* **Сетевой Клиент:** Retrofit (преобразование JSON-запросов)
* **Интеграция Карт:** Google Maps API (отображение карт и маршрутов)
* **Серверная Часть:** Node.js + Express.js (обработка запросов, API)
* **База Данных:** MongoDB (хранение данных)
* **Безопасность:** JWT (JSON Веб Токены для безопасной аутентификации пользователей)

### ⭐ Ключевые возможности
* **Аутентификация пользователей:** Логика регистрации и безопасного входа через JWT-токены
* **Архитектура REST API:** Быстрый обмен данными в формате JSON между мобильным клиентом и сервером
* **Персонализация интерфейса:** Встроенная поддержка смены тем в настройках (Светлая / Темная)
* **Информативные маркеры:** Маркеры на карте, отображающие адреса начальной и конечной точек
* **Интеллектуальные карты:** Автоматическое построение кратчайшего пути между точками А и Б
* **Интерактивный Bottom Sheet:** Выдвижная нижняя панель для оформления заказа
  
### 🖥️ HTTP Панель администратора и База данных
* **Обновление в реальном времени:** Веб-панель автоматически синхронизируется с базой данных
* **Управление пользователями:** Обновление списка пользователей, удаление учетной записи
* **Хэширование Паролей:**  Надежное хэширование паролей с использованием алгоритма BCrypt в сочетании со строгими правилами валидации (минимальная длина, требования к сложности и специальные символы) для обеспечения максимальной защиты учетных данных
