This is Taxi mobile app - open project in Android Studio

To use Admin panel and Server - open taxi server folder

Showing map requires google maps api key: 
(Ctrl + Shift + F) In Project - look for //NO SHOW (GOOGLE MAPS API) 
2 places to enter AndroidManifest.xml + google_maps_api.xml
